# PruneTime

Pruning calendar for 24 common plants: best months to prune, what to cut, and what to never cut, with hemisphere shifting. Free tool.

## Features
- Pruning calendar for 24 common plants with best months
- What-to-cut and never-cut guidance per plant
- North/South hemisphere month shifting plus tool checklist
